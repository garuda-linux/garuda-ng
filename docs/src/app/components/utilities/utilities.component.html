Utilities

Formatting pipes, table pagination state, loading tracking and small helpers shared by the Garuda Linux web projects.

Formatting pipes

Standalone pipes for the usual byte, duration, CPU-time, date and URL formatting needs.

Lazy table pagination

createLazyTablePagination() holds the page and page-size signals of a lazy PrimeNG table and derives the page from paginator events. resetPage() guards against out-of-range pages after filter changes.

Loading tracking

The loadingInterceptor counts in-flight HTTP requests and exposes a single isLoading signal through LoadingService for progress bars and skeletons.

API error messages

backendErrorMessage() extracts the message of an HTTP error response and falls back to a given default.
