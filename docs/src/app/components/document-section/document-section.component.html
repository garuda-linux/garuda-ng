Document Section

<garuda-document-section> anchors a section of a long document such as docs or policies. The section id becomes the DOM anchor for URL fragments, the heading is clickable and emits sectionSelected, and the projected body carries the shared document typography.

Usage

Inputs and outputs

  • sectionId (required) — becomes the host DOM id and the emitted value.
  • heading (required) — rendered as the clickable section heading.
  • sectionSelected — emitted with the section id when the heading is clicked.
