Charts

The charts module wraps chart.js with Catppuccin-themed helpers, a standalone chart component and custom styling plugins. It builds on the chart.js peer dependency, so no extra setup is needed.

GarudaChart

<garuda-chart> renders any chart.js configuration and re-renders whenever the config signal changes. All chart.js controllers are registered, so every chart type works out of the box. Extra plugins are passed through the plugins input; the canvas height is controlled with the --garuda-chart-height custom property.

Styled line charts

garudaLineChartOptions() returns ready-made line chart options: index-mode hover, a floating card tooltip instead of the default one (prefix values with tooltipPrefix), smooth lines with invisible points, borderless axes and K-formatted y ticks. Combine it with hoverCrosshairPlugin() for the dashed hover line and lineGradientFill() for gradient series backgrounds. Hover the chart to see the crosshair and the custom tooltip.

Theme helpers

For charts styled by hand, the theme helpers provide the Catppuccin Mocha look: mochaAxisChartOptions(), mochaPieChartOptions(), mochaLegendLabels(), mochaScales() and the CATPPUCCIN_FLAVOURS series palette.

Grouped time series

groupOverTimeChart() turns { day, group, count } rows into a multi-series line dataset. It keeps the top 10 groups by total count and zero-fills missing days so every series spans the full axis.

Customisation

All styled helpers read --garuda-chart-* custom properties and fall back to Catppuccin Mocha colours. Override them once per application to match your theme.
