Logs

The logs module renders log output in an xterm.js terminal: ANSI colours, a clickable line-number gutter, buffer search, optional interactive input and a retrying SSE stream wrapper. It builds on the @xterm/xterm peer dependencies; all xterm styling ships with the component.

GarudaLogViewerComponent

<garuda-log-viewer> receives accumulated text chunks through the chunk input and batches terminal writes, so streamed output stays smooth. Set scrollToLine to scroll to and highlight a logical line once output arrived; clicking a gutter number emits lineClick. Toggle clearSignal to reset the terminal. The host element needs a height, for example via CSS.

Live demo

Start the stream to see coloured lines append in real time. The viewer keeps the scroll position at the bottom while new output arrives; on narrow screens the gutter hides and touch scrolling takes over.

Interactive terminal

Set stdin to enable keyboard input; keystrokes arrive through the data output, and the resize output reports the new grid size after every re-fit. Together they drive a remote shell: forward data to the PTY, feed its replies into chunk, and apply resize on the other side. Without stdin the terminal stays read-only.

Methods

The component exposes findNext() and findPrevious() for buffer search, getText() for the raw buffer content, downloadLog() for a plain-text download, plus focus() and clear().

Theming and options

The theme input takes a partial xterm theme layered over the Catppuccin Mocha default and applies changes live. The options input passes extra xterm options such as scrollback or fontSize; it is read once when the terminal is created.

ResilientSseStream

ResilientSseStream wraps EventSource for live log endpoints. It reconnects with bounded backoff, re-opens dropped streams when a backgrounded tab becomes visible again, and forwards named SSE events. The URL is rebuilt per attempt, so consumers resume from their own byte offset.

Customisation

The viewer reads --garuda-log-* custom properties and falls back to Catppuccin Mocha colours. Override them once per application to match your theme.
