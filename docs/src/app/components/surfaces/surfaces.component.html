Glass Surfaces

The glass-surfaces.css stylesheet from @garudalinux/themes gives p-card, p-panel, p-tabs, p-datatable and every .garuda-surface element the shared translucent border, radius and backdrop-blur treatment. The examples below are live and use the stylesheet imported by this documentation app.

Installation

Import the stylesheet once in the application's global styles.

Usage

PrimeNG containers are styled automatically; add the class for arbitrary boxes.

Customisation

Every property is tunable through CSS custom properties with PrimeNG design token fallbacks.
